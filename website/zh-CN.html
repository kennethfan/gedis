Gedis

基于 Pebble（纯 Go LSM-tree）的 Redis 兼容存储引擎，用 Go 实现。

English · GitHub
在 GitHub 查看 快速开始

功能特性

  • Redis 兼容 — RESP2/RESP3，可作为 drop-in 替换（redis-cli 直连）
  • Pebble 存储引擎 — 纯 Go，无 CGo 依赖，WAL + 可调 fsync
  • 数据结构 — String、Hash、List、Set、Sorted Set、Geo、Bitmap、HyperLogLog、Stream（含自适应编码；Geo 复用 ZSet，Bitmap 复用 String）
  • 过期 — key 级 TTL + Hash field 过期（HEXPIRE 系），被动 + 后台主动删除
  • 主从复制 — PSYNC（全量 RDB + backlog 部分同步），只读复本
  • 内存管理 — maxmemory + 8 种逐出策略（allkeys/volatile × lru/lfu/random/ttl），CONFIG 运行时调整
  • Keyspace 通知 — CONFIG SET notify-keyspace-events KEA 全类事件（g/s/h/l/z/x/e/m），keyspace + keyevent 双频道
  • 实时命令流 — MONITOR / CLIENT MONITOR，per-conn 串行出站管道 + per-conn 写锁
  • 客户端缓存 — CLIENT TRACKING（on/off、BCAST/PREFIX、OPTIN/CACHING、OPTOUT、NOLOOP）；失效走 RESP3 push / RESP2 __redis__:invalidate
  • 监控 — INFO 六 section + SLOWLOG + Prometheus /metrics
  • 服务端 TLS — 监听口 [server] tls_cert/tls_key

快速开始

# 编译（纯静态二进制，无 CGo）
make build

# 启动（默认 gedis.toml，端口 6380）
./bin/gedis

# 使用 redis-cli 连接
redis-cli -p 6380

Docker

# 构建镜像（多阶段，scratch 运行时约 25MB）
make docker

# 单节点
docker run -d -p 6380:6380 -v gedis-data:/data gedis:latest

# 一主一从本地测试
make compose-up
redis-cli -p 6381 REPLICAOF 127.0.0.1 6380
make compose-down

配置

TOML 格式（见 gedis.toml，容器内用 gedis.docker.toml）：

[server]
host = "127.0.0.1"
port = 6380

[storage]
datadir = "./data"

[memory]
maxmemory = 1073741824
policy = "allkeys-lru"      # 或 volatile-lru

[persistence]
appendonly = true
fsync = "everysec"          # always | everysec | no

[metrics]
enabled = false
port = 9121

运行时调整：CONFIG SET maxmemory <bytes>，CONFIG SET maxmemory-policy <...>，CONFIG GET maxmemory，CONFIG SET notify-keyspace-events <KgEgse...>。

主从复制

# 从库执行（只读模式自动开启）
REPLICAOF <master-host> <master-port>

# 升主
REPLICAOF NO ONE

监控

INFO [server|clients|memory|stats|replication|keyspace]
SLOWLOG GET [n] | LEN | RESET
curl localhost:9121/metrics   # 需 [metrics] enabled

Scope（v1 未实现）

RDB 仅只读导入（--load-rdb 启动时把真机 RDB 一次性装入空库）；BGSAVE/SAVE/BGREWRITEAOF 诚实报错（无 RDB/AOF 导出）与 CONFIG REWRITE（诚实拒绝）。
