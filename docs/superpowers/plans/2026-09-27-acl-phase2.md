**Goal:** key/channel/selector 三阶鉴权完整可用，`ACL DRYRUN/LOG`、Lua 内检查、全命令 key-spec 与真机 7.2.6 对齐。

**Architecture:** `internal/acl` 加 `KeySpec` 注册表与类别表补全；`Store.CanRun` 扩展为 `Check(user, cmd, keys, channels) error`（返回 nil 或 NOPERM 三件套之一，Router 门改调它）；各 handler 文件内 `var xxxMeta` 就近登记；selectors 为 User 内多规则组 OR。

**Tech Stack:** 同一期（Go，testify，`go test ./...`，真机 7.2.6 录制）。

**Spec:** `docs/superpowers/specs/2026-09-27-acl-design.md`（§2、§4 剩余，§5 PR2 范围）

**前置：** 一期五个 Task 全部合入（`Store`、`AuthorizerStore`、`RegisterAuth/AuthRegistry`、`RegisterACL`、aclfile 可用）。

## Global Constraints

- 零用户配置时现有 `go test ./...` 零修改通过；NOPERM key 件套措辞逐字节：`NOPERM this user has no permissions to access one of the keys used as arguments`；channel 件套以真机录制为准（录制时确认，可能是 `... access one of the channels ...`）。
- `EVAL` 的 key 按 `numkeys` 语义提取；`SORT ... STORE dst`、`ZUNIONSTORE dst ...` 等目的 key 必须计入（Custom 函数）。
- commit 步骤需用户明确批准后才可执行。

## Review Focus

- `MSET k1 v1 k2 v2` 步长 key 提取：偶数位漏提即越权放行，测试必须覆盖多 key 步长。
- `EVAL "script" 2 k1 k2 a1`：numkeys=2 时只取 k1/k2，a1 不得参与 key 检查；numkeys 非法（>实参）时按 arity 错先行（handler 原有逻辑优先，鉴权门只处理合法提取）。
- selector OR 语义：任一 selector 通过即放行，测试覆盖"主规则拒绝+selector 放行"。
- `ACL DRYRUN` 不得产生副作用（不切换用户、不记 LOG），返回与真实执行一致的 OK/NOPERM。
- Lua 内 `redis.call("SET", ...)` 越权时：脚本整体中止并回 NOPERM（对齐真机），而非跳过单条继续。

```go
type KeySpec struct {
	First  int
	Last   int // -1 表末尾
	Step   int // 0/1 表逐个；2 表隔位
	Custom func(args []string) []int
}

type Meta struct {
	Name     string
	Category string
	ReadOnly bool
	Keys     KeySpec
}

var (
	metaMu sync.RWMutex
	metas  = make(map[string]Meta)
)

func RegisterMeta(m Meta) {
	metaMu.Lock()
	defer metaMu.Unlock()
	metas[strings.ToUpper(m.Name)] = m
}

func LookupMeta(cmd string) (Meta, bool) {
	metaMu.RLock()
	defer metaMu.RUnlock()
	m, ok := metas[strings.ToUpper(cmd)]
	return m, ok
}

func ExtractKeys(cmd string, args []string) []string {
	m, ok := LookupMeta(cmd)
	if !ok {
		return nil
	}
	if m.Keys.Custom != nil {
		var out []string
		for _, i := range m.Keys.Custom(args) {
			if i >= 0 && i < len(args) {
				out = append(out, args[i])
			}
		}
		return out
	}
	step := m.Keys.Step
	if step <= 0 {
		step = 1
	}
	last := m.Keys.Last
	if last < 0 || last >= len(args) {
		last = len(args) - 1
	}
	var out []string
	for i := m.Keys.First; i <= last; i += step {
		out = append(out, args[i])
	}
	return out
}

func sortStoreKey(args []string) []int {
	idx := []int{0}
	for i := 1; i < len(args); i++ {
		if strings.EqualFold(args[i], "STORE") && i+1 < len(args) {
			idx = append(idx, i+1)
			break
		}
	}
	return idx
}
```

EVAL 提取器（同文件）：`func evalKeys(args []string) []int`——args[0]=numkeys 解析 n，返回 1..n（n 非法/超界返回空，handler 侧 arity 错优先）。
