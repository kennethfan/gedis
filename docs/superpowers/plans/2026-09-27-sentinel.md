# Sentinel 最小发现版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Gedis 加上独立哨兵端口的最小发现版 Sentinel（静态 masters + 手动 FAILOVER，复用 REPLICAOF）。

**Architecture:** 同一二进制双 listener：数据口零改动；哨兵口用新 `network.Router` + 新包 `internal/sentinel.Registry`（静态注册表 + 周期 PING 探活 + 手动翻主），`SENTINEL FAILOVER` 时哨兵作为客户端直连数据节点发 `REPLICAOF`，复用现有复制链路。

**Tech Stack:** Go 1.23+, `net.DialTimeout` 探活，`internal/network.Router/Server`，`internal/protocol.Value`，TOML config（BurntSushi/toml，经 `config.Load`）。

**Spec:** `docs/superpowers/specs/2026-09-27-sentinel-design.md`

## Global Constraints

- Go 版本与现有 go.mod 一致，不新增外部依赖。
- 哨兵口默认 26379，`[sentinel]` 缺席即关闭，现有单节点启动行为零变化。
- `quorum` 最小版固定展示 1，不实现选举；`SENTINEL set/remove` 一律静态拒绝。
- 全 down 时 `get-master-addr-by-name` 返回最后缓存主，不返回空。
- 端口隔离：`SENTINEL` 在数据口未知命令；数据命令在哨兵口拒绝。
- 测试门禁：`go build ./...`、`go vet ./...`、`go test ./...` 全绿。

## Review Focus

- `down_after_ms=0` 时跳过探活但 `get-master-addr` 仍返回配置主，期望永不清 down 标记。
- `SENTINEL failover` 在全 slave down 时回 `ERR No healthy slave` 且不翻转缓存主。
- 旧主不可达时 failover 不回滚已提升的新主，只翻缓存并继续返回 `+OK`。
- `SENTINEL` 发到数据口时返回与 Redis 7.2 一致的 unknown-command 措辞，而非静态拒绝文案。
- 并发 failover 同 name 串行，第二个调用阻塞等待而非并发双切。

---

## File Structure

- `internal/config/config.go`（改）：加 `Sentinel Sentinel` 字段 + `SentinelMaster` 结构 + `Specs()` 校验展开。
- `internal/sentinel/registry.go`（新）：`Registry` 静态注册表（master 名 → 主地址/slaves/当前主/down 标记，RWMutex），`ProbeOnce`、`Failover`、`GetMasterAddr`。
- `internal/sentinel/probe.go`（新）：周期探活循环（`DialTimeout+PING`），`down_after_ms=0` 跳过。
- `internal/commands/sentinel.go`（新）：`RegisterSentinel(r *network.Router, reg *Registry)`，只注册 `SENTINEL/PING/INFO/SUBSCRIBE` 子集。
- `cmd/gedis/main.go`（改）：`[sentinel]` enabled 时起第二 `Router+Server+Listener`（哨兵口），`defer` 关闭与信号关闭一并处理。
- `internal/sentinel/registry_test.go`、`internal/config/config_test.go`（改/新）：单元测试。
- `internal/commands/sentinel_accept_test.go`（新）：fixtures 对齐的验收测试。
- `testdata/sentinel/*.redis`（新）：真机 7.2.6 录制（masters/master/slaves/get-master-addr + failover 翻转）。
